# Make.com Scenarios

A collection of Make.com automation blueprints — each folder contains a ready-to-import scenario with setup instructions.

## Scenarios

| Scenario | Description |
|----------|-------------|
| [GmailEvents_To_Calendar](./GmailEvents_To_Calendar) | Extracts events from Gmail using Gemini AI and adds them to Google Calendar |

## How to Use

1. Download the `blueprint.json` from any scenario folder
2. In Make.com go to your scenario → `...` → **Import Blueprint**
3. Reconnect all required connections
4. Follow the setup guide in the scenario's `README.md`
